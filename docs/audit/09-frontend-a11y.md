# 09 Frontend und Barrierefreiheit (FitTrack, `src/components`, `src/features`)

Stand 2026-11-12. Nur gelesen, nichts geändert, nichts gestartet, keine Datenbankinhalte, keine Screenshots. Maßstab: WCAG 2.1 AA (Skill `design:accessibility-review`), Prüfkriterien des Skills `impeccable`. Kontrast aus den Tokens in `src/app/globals.css` gerechnet (OKLCH nach sRGB). Fundstellen beziehen sich auf `src/`. Nicht mit VoiceOver oder auf dem Gerät getestet; was nur aus dem Code folgt, steht als Vermutung.

## Zusammenfassung

1. KB-09 („hängt“): `workout-detail.tsx` fragt eine aktive Einheit jede Sekunde ab und ersetzt bei jeder Antwort das gesamte `workout`-Objekt. Daraus folgen pro Sekunde: Re-Render der 2259-Zeilen-Komponente und aller Übungskarten, IndexedDB-Schreibzugriff, Push an die Watch, drei Brücken-/IDB-Aufrufe. Zusätzlich lädt jedes `fittrack-offline-synced`-Ereignis (auch bei App-Resume) die Seite mit Skeleton neu und zerstört dabei halb eingetippte Satzwerte.
2. KB-11 („Statusanzeige falsch“): Es gibt nur ein 12-px-Symbol, nur mobil, nur aus `navigator.onLine`; „ausstehend“ und „Sync fehlgeschlagen“ haben keine dauerhafte Anzeige (die vorgesehenen Texte `offline.syncing`/`offline.pendingCount` sind ungenutzt). Der Banner für die aktive Einheit verschwindet bei jedem fehlgeschlagenen Abruf.
3. KB-10 („Cardio hängt“): Beenden/Abbrechen läuft über natives `confirm()`, das im Code selbst als unzuverlässig im WKWebView beschrieben ist; die Live-Ansicht zeigt keine Fehler (PiP-Fehler unsichtbar) und wartet ohne Zeitlimit auf Daten.
4. Fehler erscheinen oft nur über `window.alert` (8 Stellen, darunter „Training beenden fehlgeschlagen“): derselbe Mechanismus, den die Datei an anderer Stelle als unzuverlässig umgeht.
5. Barrierefreiheit: Satzfelder ohne Label auf dem Handy, Name-Felder ohne Fokusanzeige, Zeitgeber als Live-Region mit Sekundentakt, Wechselschalter ohne `aria-pressed`, Kontrastlücken im hellen Theme, einzelne englische/deutsche Festtexte außerhalb von `de.json`.

Anzahl: kritisch 0, hoch 5, mittel 12, niedrig 7.
