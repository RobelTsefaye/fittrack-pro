# Audit 03 – Abhängigkeiten FitTrack (2026-11-12)

Nur Lesezugriff. Keine Installation, keine Änderung an Code oder Lockfiles. Grundlage: `npm audit` und `npm outdated` gegen Registry (Netz vorhanden), `package.json`, `package-lock.json`, `node_modules/*/package.json` (Lizenzfelder), Grep über `src/`, `scripts/`, `prisma/`, Config-Dateien.

## Zusammenfassung

1. `npm audit` (Root): 56 Befunde (7 kritisch, 20 hoch, 21 mittel, 8 niedrig). Am wichtigsten: `next` 16.2.2, `next-auth` 5 beta, `@capacitor/ios` 8.4.1 (je kritisch), `prisma` und `zod` (hoch).

4. Lizenzen: alle direkten Laufzeitabhängigkeiten permissiv (MIT, Apache-2.0, BSD-3-Clause, ISC). Copyleft nur transitiv (LGPL, MPL), kein Befund mit Handlungsbedarf für eine private App.
5. Findings: kritisch 3, hoch 5, mittel 3, niedrig 7 (18 gesamt). Keine CI-Prüfung auf Abhängigkeiten vorhanden.
